# MMM, o Site Mais Otaku do Mundo. 
> O marketplace de mangás, como uma "feirinha" virtual para conectar quem quer comprar, vender ou trocar um mangá.
> ## O que é:
> A MMM é um marketplace de marketplace aberto, onde qualquer pessoa pode publicar o próprio mangá, com a opção de vender, trocar ou ter abertura para os 2.
>
> Nosso objetivo é criar um ambiente de troca e venda, como uma feira, só que online, conectando otakus, vencendo barreiras físicas que muitas vezes separam eles.
> 
> Apresentamos um ambiente especializado em produtos otaku, onde você pode encontrar uma comunidade parceira e produtos do nicho mais facilmente.
>
## 💻 Tecnologias utilizadas

- **HTML** — Estrutura das páginas.
- **CSS** — Estilização e aparência.
- **JavaScript** — Funcionalidades e interatividade.
- **Python** — Desenvolvimento do sistema.
- **PostgreSQL** — Banco de dados.
- **Git** — Controle de versão.
